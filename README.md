# Prior Inventions

A dated list of what you built on your own, ready before you sign your next employment or contractor agreement. Claude finds your candidates, dates each one from a record you can check, and saves them to your own Prior Inventions page, where you approve them and download the Exhibit for an employer.

Free for personal use. Get it at https://doovli.app/prior-inventions.html

## What is in this repository

| Path | What it is |
|---|---|
| download/Prior Inventions v2.0.3.zip | The package people download: Install Guide, Setup Prompt, the page file and the Keep It Current skill. |
| prior-inventions.html | The current page. The Update now button installs this file. |
| version.json | The current version number and release note. The monthly check reads it. |
| tasks/update.txt | The current instructions for the monthly update task. |
| skill/prior-inventions-keep-current/SKILL.md | The current Keep It Current skill. |
